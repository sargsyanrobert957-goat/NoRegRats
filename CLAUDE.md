# NoRegRats

Unity 6 project (editor 6000.6.5f1), C#.

- Scripts go in `Assets/Scripts/`. Create the folder if it doesn't exist yet.
- Don't edit `.meta` files by hand. Unity generates them, and each one must stay next to its asset. Move or rename assets inside the Unity editor so their `.meta` files follow.
- Scenes are in `Assets/Scenes/`.
- `Library/`, `Temp/`, `Obj/`, `Logs/`, `UserSettings/` and the generated `.csproj`/`.slnx` files are regenerated by Unity and ignored by git. Don't edit or commit them.
